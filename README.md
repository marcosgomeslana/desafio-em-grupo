# Desafio em Grupo - PUC Tech: Debates & Dilemas Absurdos

## Sobre o desafio

Nesta dinâmica, cada integrante deverá responder às perguntas propostas em sua própria branch. Como diferentes respostas serão desenvolvidas simultaneamente, o grupo deverá utilizar o processo de **merge e resolução de conflitos no Git** para reunir as contribuições na branch `main`.

A ideia é transformar os conflitos em uma oportunidade de colaboração: ao encontrar respostas diferentes para uma mesma pergunta, o grupo deverá **discutir, negociar e chegar a um consenso**, podendo inclusive combinar as ideias para criar uma resposta ainda mais absurda.

## Instruções para o grupo

1. Cada integrante deve responder às perguntas na sua própria branch.
2. Ao resolver os conflitos de merge na main, o grupo DEVE negociar e entrar em um consenso (ou criar uma resposta ainda mais absurda fundindo as ideias)!
